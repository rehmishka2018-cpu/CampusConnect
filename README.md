# CampusConnect

CampusConnect is a responsive school campus website designed to provide students with important campus information in one place.

## Features

- Responsive navigation
- Upcoming events section
- Dynamic event details using JavaScript
- Student clubs section
- Campus announcements
- Event registration through a modal form
- Registration form validation
- Registration success feedback
- Contact form
- Responsive design for desktop and mobile devices
- Smooth scrolling and UI animations

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
